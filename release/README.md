# layer_time_change

一个用于修改 G-code 打印速度、从而实现「层时间阶梯」的切片软件后处理脚本。

它的工作原理与温度阶梯脚本类似：从切片软件的输入输出流中读取生成的 G-code，
按需求计算并修改打印速度指令（`G1 F...`），再把修改后的 G-code 写回原路径。
参数输入通过 gpui 图形窗口完成，不再使用终端。

通过改变不同高度的打印速度，即可改变对应层的层时间。常用于研究不同层时间对
打印质量（如强度、外观、悬垂）的影响。

## 原理

方管模型每层的打印路径周长约等于：

```
周长(mm) = 边长 × 4 × 壁数
```

给定目标层时间 `T`（秒），对应的打印速度为：

```
速度(mm/min) = 边长 × 4 × 壁数 / T × 60
```

> G-code 默认速度单位是 mm/min，所以需要乘以 60。

### 自动阶梯算法

从第 0 层（切片软件的第一层）开始，每过一个「间隔层数」，层时间降低一次：

```
层时间 = 初始层时间 - floor(层号 / 间隔层数) × 变化量
```

例如默认参数下：

| 层号 | 层时间 | 速度 |
| --- | --- | --- |
| 第 0 层 | 8 s | 2400 mm/min |
| 第 100 层 | 7.5 s | 2560 mm/min |
| 第 200 层 | 7 s | 2742.857 mm/min |

## 三种模式

运行后会弹出一个图形窗口（gpui），点击选择以下三种模式之一：

| 模式 | 说明 |
| --- | --- |
| 默认参数 | 使用内置参数自动生成层时间阶梯 |
| 自定义参数 | 在窗口中输入参数后自动生成层时间阶梯 |
| 使用切片中不同层高处输入的参数 | 层时间完全由 G-code 中插入的纯数字决定 |

### 1. 默认参数

显示内置的默认参数，点击「应用」后处理 G-code。

### 2. 自定义参数

依次输入：

1. 方管边长 (mm)
2. 方管壁数（圈数）
3. 初始层时间 (s)
4. 层时间变化量 (s)（每个间隔降低的时间）
5. 间隔层数

输入完成后处理 G-code。

### 3. 切片中输入的参数（纯数字标记）

该模式只要求输入方管边长和壁数，层时间则由你在切片软件里插入的纯数字决定。

在 OrcaSlicer 的某个「层切换自定义 G-code」中插入一个纯数字（例如 `6` 或 `6.5`），
即表示「从这一层起，层时间变为 6 秒」。脚本会：

1. 根据边长、壁数和该层时间计算打印速度；
2. 找到该层的打印速度指令 `G1 F...`，修改为计算后的速度；
3. 把该纯数字行转成注释 `; layer_time_change: 6s`，避免残留无效 G-code。

该标记会持续生效到下一个纯数字标记为止。没有标记的层保持原速度不变。

## 默认参数

| 参数 | 默认值 |
| --- | --- |
| 方管边长 | 40 mm |
| 方管壁数 | 2 |
| 初始层时间 | 8 s |
| 层时间变化量 | 0.5 s |
| 间隔层数 | 100 层 |

## 构建

需要安装 Rust 工具链（Cargo），以及 gpui 在 Windows 上的依赖（D3D12）。

```bash
cargo build --release
```

Windows 上 release 构建还需要 Windows SDK 的 `fxc.exe`。如果它不在 `PATH` 中，可以通过 `GPUI_FXC_PATH` 指定：

```bash
GPUI_FXC_PATH="D:/Windows Kits/10/bin/10.0.26100.0/x64/fxc.exe" cargo build --release
```

生成的可执行文件位于：

- Windows: `target/release/layer_time_change.exe`
- Linux/macOS: `target/release/layer_time_change`

## 在 OrcaSlicer 中使用

1. 完成上述构建。
2. 打开 OrcaSlicer：`其他选项` → `后处理脚本`。
3. 添加生成的可执行文件路径。
4. 正常切片。切片完成后脚本会被自动调用，并弹出图形输入窗口。

脚本接收的第一个命令行参数是 G-code 文件路径（由 OrcaSlicer 自动传入）。
也可以手动调用：

```bash
layer_time_change.exe "D:\path\to\model.gcode"
```

## 注意事项

- 层时间计算假设每层路径周长 = `边长 × 4 × 壁数`。请确保模型为方管，且实际壁数
  与设置的壁数一致，否则层时间会有偏差。
- 层号采用切片软件的 0 基编号：第一个 `;LAYER_CHANGE` 为第 0 层。
- 只修改独立的 `G1 F<数字>` 速度指令；擦嘴（`;WIPE_START`/`;WIPE_END`）段、
  行程和回抽速度不会被改动。
- 纯数字标记与温度阶梯脚本共用「纯数字行」的约定，请不要在同一个 G-code 中
  混用两种用途的数字。
